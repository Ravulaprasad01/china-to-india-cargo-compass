# ImportNow — China to India Cargo Compass

A complete rebuild of the ImportNow concept website, developed as a practical assignment for the **AI Executive – Website & Automation Development** role at ImportNow, Hyderabad.

**Live Website:** [importnow.lovable.app](https://importnow.lovable.app/)  
**Reference Website:** [importnow-concept.vercel.app](https://importnow-concept.vercel.app)

## Project Overview

ImportNow helps Indian businesses source and import products directly from China, managing the entire process — from supplier sourcing and factory inspections to international shipping, customs clearance, and doorstep delivery.

This project involved rebuilding the original ImportNow website from scratch, focusing on preserving its content, visual direction, and core user interactions while recreating complex visual elements using practical, lightweight alternatives.

The website includes all ten sections of the original reference site.

## Key Features

### 1. Hero Section
- Engaging headline and animated statistics.
- Interactive 2D map highlighting major sourcing locations in China.
- Visual representation of the China-to-India trade route.

### 2. Services
- Six end-to-end import services.
- Covers supplier sourcing, quality inspection, shipping, customs, and delivery.

### 3. How It Works
- Six-step import process.
- Animated shipment timeline illustrating the Shanghai-to-Chennai route.

### 4. What We Import
Six industry-specific sourcing hubs:
- Foshan — Furniture
- Shenzhen — Electronics
- Guangzhou — EV & Automotive
- Guzhen — Lighting
- Yiwu — General Goods
- Pan-China — Machinery

Includes interactive category filters.

### 5. Officially in China
- Highlights the company's registered presence in Shanghai.
- Showcases the Shanghai Shengqiao Chain Trading Co., Ltd. licence information.

### 6. Business Trips to China
- Canton Fair business trips.
- Trip inclusions and upcoming departure information.

### 7. Recently Delivered
- Showcases four completed delivery projects.

### 8. Client Stories
- Interactive testimonial carousel.

### 9. Import Guides & FAQs
- Import-related guide cards.
- Six frequently asked questions with expandable answers.

### 10. Request a Quote
- Validated quote request form.
- Opens WhatsApp with the visitor's submitted details pre-filled.

## Tech Stack

- **Frontend:** React.js, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Development & Deployment:** Lovable

## Getting Started

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/Ravulaprasad01/china-to-india-cargo-compass.git

# Navigate into the project
cd china-to-india-cargo-compass

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### Production Build

```bash
npm run build
```

## Implementation Decisions & Simplifications

Some of the original website's complex visual elements were recreated using simpler alternatives while retaining their core purpose:

| Original Website | Rebuilt Implementation |
|---|---|
| Interactive 3D globe | Interactive 2D sourcing map |
| 3D port animation | Animated 2D shipment timeline |
| Full import guide articles | Guide preview cards |

The remaining sections, reference copy, contact details, and WhatsApp quote flow were recreated to stay consistent with the original website.
